# Demo script (about 100 seconds)

## 0–45 seconds: product

1. Open the deployed dark dashboard on desktop.
2. Add a USD expense and show the monthly total and category bar.
3. Edit it. Show that the total changes.
4. Use Chromium's Network tab to go offline. Reload, add another expense, and reload again.
5. Export a JSON backup.

## 45–85 seconds: agent workflow

1. Show the product spec commit before the product-code commit.
2. Show `AGENTS.md` and one linked rule change.
3. Show the harness checkpoint, a maker turn, deterministic checks, and a separate read-only checker report.
4. Show one real failure and its regression test. Do not present synthetic harness fault tests as product defects.

## 85–110 seconds: ownership and result

State that the human chose USD, dark UI, local storage, scope, model budget, and no physical phone tests. State that agents wrote the product, tests, CI, docs, and fixes within those constraints. Show the CI result and deployed URL. Keep the recording between one and two minutes.
